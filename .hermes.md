# RealtorOS

Система для работы с недвижимостью (агентство). OCR, документооборот, сделки.

## Пути

- **Корень проекта**: `/home/xiag/real-estate-os/`
- **Фронтенд**: `/home/xiag/real-estate-os/frontend/` (Next.js App Router)
- **Бэкенд**: `/home/xiag/real-estate-os/backend/` (Python FastAPI)

## Домены

- ai.spcnn.ru → localhost:3000 (Next.js)
- api.spcnn.ru → localhost:8090 (FastAPI)
- spcnn.ru → localhost:8080
- o-p.pro → localhost:8000

## Стек

- **Бэкенд**: Python 3.13, FastAPI (async), SQLAlchemy async
- **Фронтенд**: Next.js (App Router)
- **База данных**: PostgreSQL
- **OCR**: OCRNode (Tesseract 5, CPU-only, rus+eng) через `/api/v1/processing/pipelines/start/`
- **LLM**: Qwen2.5-32B at localhost:8002 (llama.cpp server)

## Сборка / запуск

```bash
# Полный перезапуск
cd /home/xiag/real-estate-os && bash deploy/restart.sh

# Backend dev
cd /home/xiag/real-estate-os && uvicorn app.main:app --reload --port 8090

# Frontend dev
cd /home/xiag/real-estate-os/frontend && npm run dev
```

## Жизненный цикл документа

UPLOADED → VALIDATED → ACCEPTED → PROCESSING → ANALYZED → READY → ROUTED → ARCHIVED

## Импорт документов

7 шагов: select → upload → ocr → analyze → deal → deal_created → done
Страница: `/imports/documents`
